# Python To-Do List CLI Application

## Project Description
The Python To-Do List CLI Application is a simple task management program developed using Python. It allows users to manage their daily tasks through a command-line interface.

## Technologies Used
- Python
- Visual Studio Code
- Command Line Interface (CLI)

## Features
- Add new tasks
- View all tasks
- Remove tasks
- Exit the application

## Installation and Setup

1. Install Python on your laptop.
2. Download this repository from GitHub.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python todo.py
```

## How to Use

Select an option from the menu:

1. Add Task
2. View Tasks
3. Remove Task
4. Exit
